# Requirements - VSCode Class Diagram & Workflow Editor

## 1. Vision & Purpose
VS Code 内で視覚的にクラス図やワークフロー図を作成し、それらの設計から多言語のソースコード（TypeScript, Java, C#, C++, Rust）の雛形を自動生成することを目的とした拡張機能です。

## 2. Target Users
- VS Code をプログラミングのメインエディタとして使用している開発者。
- クラス設計からコーディングの流れを効率化したい開発者。
- 視覚的なドキュメント（図）とソースコードの同期を重視する開発者。

## 3. Core Features

### 3.1. エディタ機能
- **クラス図エディタ**:
  - クラス、インターフェースのビジュアル作成。
  - プロパティ（フィールド）およびメソッド（操作）の定義。
  - 継承、インターフェース実装の指定。
  - 抽象・仮想要素のサポート。
- **ワークフロー図エディタ**:
  - シンプルなワークフローのビジュアル作成。

### 3.2. コード生成機能
- **対応言語**: TypeScript, Java, C#, C++, Rust。
- **データマッピング**: クラス図上の抽象型から各言語のプリミティブ型への自動変換。
- **特殊処理**: C++ における `List<T>` から `std::vector<T>` への変換など。

### 3.3. データ管理
- **JSONベース**: 図の情報を `diagram.json` として保存・読み込み可能。

## 4. Constraints & Limitations
- **リバースエンジニアリング**: ソースコードから図面への変換は現在サポート外。
- **コード生成の制約**: private かつ abstract/virtual なメンバなど、不適切な組み合わせはスキップされる。

## 5. Success Criteria
- クラス図からエラーなくターゲット言語のソースコードが生成されること。
- `diagram.json` を介して図の状態を完全に復元できること。
