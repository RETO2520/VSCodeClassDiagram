# Product Vision - VSCode Class Diagram & Workflow Editor

## 1. Vision Statement
開発者が設計（図）と実装（コード）をシームレスに行き来できる環境を提供し、アイディアを即座に構造化されたソースコードへ変換可能にする。特に、ワークフロー図からロジックの骨組みを自動生成することで、実装のスピードと品質を向上させる。

## 2. Goals
- **直感的なモデリング**: 専門的な UML 知識がなくても、マウス操作で簡単にクラス構造やワークフローを定義できる。
- **ワークフローのコード変換**: ワークフロー図から実行可能なコード（または詳細なスケルトン）を生成する。エディタ側は「扱いやすいデータモデル（抽象構文木に近い形式）」の構築に専念し、実際のコード変換は各言語のビルダーに委ねる。
- **マルチプラットフォーム・マルチ言語**: 現代的なソフトウェア開発で利用される主要な言語（TypeScript, Java, C#, C++, Rust）を網羅する。
- **ポータビリティ**: `diagram.json` 形式を採用することで、設計データをバージョン管理システム（Git等）で容易に共有・管理できる。

## 3. Target Audience
- **個人開発者**: 手軽にクラス設計やロジックの流れを定義し、ボイラープレートコードや複雑な分岐・ループ構造の生成を自動化したい。
- **教育・学習者**: 設計図と実際のコードの関係を視覚的に学び、アルゴリズムの視覚化から実装への移行をスムーズに行いたい。
- **小規模チーム**: 設計の意図（クラス構造だけでなくビジネスロジックの流れ）を視覚的に共有し、実装の不整合を防ぎたい。

## 4. Success Metrics
- 拡張機能のインストール数およびアクティブユーザー数。
- 生成されたコード（特にワークフロー由来のロジック）に対するユーザー満足度。
- 対応言語の拡充と、条件分岐や繰り返しを含む高度なワークフローからの正確なコード生成。
