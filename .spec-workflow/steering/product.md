# Product Vision - VSCode Class Diagram & Workflow Editor

## 1. Vision Statement
開発者が設計（図）と実装（コード）をシームレスに行き来できる環境を提供し、アイディアを即座に構造化されたソースコードへ変換可能にする。

## 2. Goals
- **直感的なモデリング**: 専門的な UML 知識がなくても、マウス操作で簡単にクラス構造やワークフローを定義できる。
- **マルチプラットフォーム・マルチ言語**: 現代的なソフトウェア開発で利用される主要な言語（TypeScript, Java, C#, C++, Rust）を網羅する。
- **ポータビリティ**: `diagram.json` 形式を採用することで、設計データをバージョン管理システム（Git等）で容易に共有・管理できる。

## 3. Target Audience
- **個人開発者**: 手軽にクラス設計を行い、ボイラープレートコードの生成を自動化したい。
- **教育・学習者**: クラス設計と実際のコードの関係を視覚的に学びたい。
- **小規模チーム**: 設計の意図を視覚的に共有し、実装の不整合を防ぎたい。

## 4. Success Metrics
- 拡張機能のインストール数およびアクティブユーザー数。
- 生成されたコードに対するユーザー満足度（Issue や Feedback ベース）。
- 対応言語の拡充と、コード生成ロジックの正確性向上。
